# about-me-e2e

E2E tests powered by Playwright.

Русскоязычный практический гайд: [PLAYWRIGHT_GUIDE_RU.md](./PLAYWRIGHT_GUIDE_RU.md).

## Commands

```bash
npm test
npm run test:ui
npm run test:headed
npm run report
```

Set `BASE_URL` to target a non-default application URL:

```bash
BASE_URL=https://example.com npm test
```
